## Why is it down?

WR Editor Fix is a FiveM `.asi` plugin for the Rockstar Editor. To make sure it fully follows the rules for `.asi` plugins on FiveM, it is being reworked from the ground up. Until that work is finished and checked, no version is available for download.

## Already using it?

| Your version | What to do |
|---|---|
| **v1.0.0 or older** | Remove it now. |
| **v1.0.1** | Safer than everything before it, but it was made before this safety check. Use at your own risk; removing it until v1.1.0 is recommended. |

**How to remove it:** close FiveM, open `%localappdata%\FiveM\FiveM.app\plugins` and delete `WR_Editor_Fix.asi`.
Your settings, presets and projects in the `WR Editor Fix` folder can stay. v1.1.0 uses the same folder.
